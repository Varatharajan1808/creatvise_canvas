# AI test fixtures

## Real Illustrator live text (manual)

Place a genuine Illustrator save at **`illustrator-live-text.ai`**.  
Full requirements and parser rules: **[ILLUSTRATOR-LIVE-TEXT-FIXTURE.md](./ILLUSTRATOR-LIVE-TEXT-FIXTURE.md)**.

Verify with:

```bash
npx tsx scripts/ai-live-text-fixture-audit.ts
```

Expect `fixtureClass: "illustrator-live-text-ready"` (not `synthetic`).

## `simple-shapes.ai`

Minimal PDF-compatible file with one **rectangle** path (fill + stroke) in a marked-content block. Used by `scripts/ai-shape-export.test.ts` and `scripts/ai-export-fidelity.test.ts`. Regenerated by `scripts/ai-pdf-text.test.ts` (`ensureAiFixtures()`).

## `simple-placed-image.ai`

Minimal **PDF-compatible** synthetic file with one OCG, one marked-content block, and one **FlateDecode / DeviceRGB** image XObject (`cm` + `Do`).

- Used by `scripts/ai-image-replacement.test.ts` for Phase 3 **embedded-image detection** only.
- **Not** exported from Adobe Illustrator.
- Regenerated when the image detection test runs (`ensureFixtureOnDisk()`).

## `live-text-synthetic.ai`

Minimal **PDF-compatible** file with one marked-content block and live PDF text operators (`BT` … `(…) Tj` … `ET`).

- Used by `scripts/ai-pdf-text.test.ts` for Phase A live-text **detection** only.
- **Not** exported from Adobe Illustrator — does **not** prove Illustrator desktop round-trip or AIPrivateData compatibility.
- Regenerated when the text parser test runs (same bytes as `buildSyntheticLiveTextPdf()` in that script).
